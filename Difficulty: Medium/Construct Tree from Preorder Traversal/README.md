<ul>
<li><span style="font-size: 14pt;">pre[] represents the preorder traversal of a&nbsp;</span><span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif; font-size: 14pt;"> <a href="https://www.geeksforgeeks.org/dsa/full-binary-tree/" target="_blank" rel="noopener">full binary tree</a></span><span style="font-size: 14pt;"> (Every node has 0 or 2 Children).</span></li>
<li><span style="font-size: 14pt;">preLN[i] stores 'L' if pre[i] is a leaf node and 'N' if a non-leaf node.</span></li>
