<h2><a href="https://www.geeksforgeeks.org/problems/kth-common-ancestor-in-bst/1?page=6&category=Tree&sortBy=submissions">Kth common ancestor in BST</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color); --darkreader-text--text-color: var(--darkreader-text--problem-text-color); --darkreader-border--text-color: var(--darkreader-border--problem-text-color);"><p><span style="font-size: 18.6667px;">Given a <strong>Binary Search Tree (BST)</strong> with<strong> n</strong> (n ≥ 2) nodes and two <strong>distinct</strong> nodes <strong>x</strong> and <strong>y</strong>, find their <strong>k-th common ancestor</strong>.</span></p>
<p><span style="font-size: 18.6667px;">Return the value of the k-th common ancestor of x and y. If fewer than k common ancestors exist, return <strong>-1</strong>.</span></p>
<p><span style="font-size: 18.6667px;">It is guaranteed that both x and y are present in the BST and x ≠ y.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input: <br></strong><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/927760/Web/Other/blobid1_1777973807.png" width="245" height="225"><br>k = 2, x = 40, y = 60 <br><strong>Output: </strong>30<br><strong>Explanation: </strong>Their 2nd common ancestor is 30.</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input: <br><img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/927760/Web/Other/blobid2_1777973876.png" width="275" height="213"><br></strong>k = 2, x = 40, y = 60<br><strong>Output: </strong>-1<br><strong>Explanation: </strong>Lowest Common Ancestor of 40 and 60 is 50, which is root itself. There does not exists 2nd common ancestor in this case.</span></pre>
