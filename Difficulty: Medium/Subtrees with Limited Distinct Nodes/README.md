<h2><a href="https://www.geeksforgeeks.org/problems/good-subtrees--170647/1">Subtrees with Limited Distinct Nodes</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">You are given a <strong>root</strong> node of a binary Tree and each node of the binary tree is assigned a <strong>value</strong> and you&nbsp;are also given an integer <strong>k</strong> and you have to return the count of <strong>Good subtrees</strong> of this binary tree . </span></p>
<p><span style="font-size: 18px;">Good subtree is a subtree such that the <strong>number</strong> of <strong>distinct</strong>&nbsp;<strong>values</strong>&nbsp;in this subtree is less than or equal to k.</span></p>
<p><span style="font-size: 18px;"><strong>Note</strong>: Subtree of a node consists of that node and all nodes of the subtrees of left and right child&nbsp;&nbsp;of that&nbsp;node&nbsp;&nbsp;if they exist .</span></p>
<p><strong><span style="font-size: 18px;">Examples:</span></strong></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>root[] = [1, 2, 2, 3, N, 5, 4], </span><span style="font-size: 18px;">k = 2<br>         <img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/928579/Web/Other/blobid1_1779444279.png" width="195" height="127"><br></span><span style="font-size: 18px;"><strong>Output</strong>: 4
<strong>Explanation: </strong>All leaves 3, 4 and 5 form good subtrees as number of distinct values in subtrees is 1 which is less than k (or 2). Now subtree which starts at 2 and has 3 as left node is also a good subtree because the count of distinct values is 2 which is equal to k so overall 4 good subtrees.</span></pre>
<pre><strong><span style="font-size: 18px;">Input: </span></strong><span style="font-size: 18px;">root[] = [1, 2, 2, 2, N, N, 2]</span><span style="font-size: 18px;">, </span><span style="font-size: 18px;">k = 1<br>         <img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/928579/Web/Other/blobid2_1779444315.png" width="196" height="127"></span>
<span style="font-size: 18px;"><strong>Output: </strong>4
<strong>Explanation: </strong>All leaves (2 and 2) form good subtrees as number of distinct values in subtrees is 1. Now  both subtrees which starts at 2 and has 2 as child also form a good subtree as count of distinct values is 1 which is equal to k so overall 4 good subtrees.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints</strong>:<br>1 ≤ n ≤ 10<sup>5</sup>, n is number of nodes in binary Tree<br>1 ≤ node.data ≤ 25<br>1 ≤ k ≤ 20<br>The sum of n over all test cases won't exceed 5*10<sup>5</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>DFS</code>&nbsp;
